# Envryn 0.1.9 beta

This release focuses on confidence. Envryn now exercises its desktop and mobile layouts in a real browser, checks accessibility, enforces coverage and bundle budgets, and has a more accurate Android dependency scan.

## Highlights

- Added desktop and Pixel 7 browser journeys for onboarding, vault navigation, sync, and settings.
- Added automated WCAG A and AA checks for serious and critical accessibility problems.
- Added frontend coverage thresholds and JavaScript/CSS bundle budgets.
- Expanded the frontend suite to 83 unit and component tests.
- Fixed the recurring SonarQube Cloud security rating failure caused by an unpinned `npx` workflow command.
- Updated the Android runtime to Jackson 2.18.9 and verified the dependency graph that actually ships in the APK.
- Added fresh desktop and mobile product screenshots plus a clearer documentation and contribution experience.

## Downloads

- **Android:** `Envryn_0.1.9_android-universal.apk`
- **Windows setup:** `Envryn_0.1.9_x64-setup.exe`
- **Windows MSI:** `Envryn_0.1.9_x64_en-US.msi`
- **Checksums:** `CHECKSUMS.txt`
- **Software bill of materials:** `Envryn_0.1.9_SBOM.cdx.json`

The Android package uses the established Envryn release identity. Windows packages are not code-signed yet, so Windows may show an unknown publisher warning. Verify downloads with `CHECKSUMS.txt`.

## Verification

- Rust formatting and strict Clippy checks passed.
- The complete Rust workspace test suite passed.
- 83 frontend unit and component tests passed.
- Desktop and mobile browser journeys passed.
- Serious and critical accessibility checks passed.
- Frontend coverage and bundle budgets passed.
- npm audit, OSV-Scanner, Gitleaks, Semgrep, CodeQL, SonarQube Cloud, `cargo-audit`, `cargo-deny`, and security invariants passed or contained only documented reviewed exceptions.
- The Android release APK and both Windows installer formats were built from the tagged commit.

## Before upgrading

Envryn remains beta software. Keep an encrypted backup of important vault data. Installing over an existing Windows installation leaves the vault in place. Android updates require the existing Envryn signing identity.
