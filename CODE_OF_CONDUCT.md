# Community code of conduct

Envryn should be a place where people can contribute, ask questions, and disagree without being treated poorly.

## Our standard

Please:

- Be respectful and patient.
- Critique ideas and code, not people.
- Assume good intent while still being clear about risk.
- Welcome contributors with different backgrounds and experience levels.
- Protect private information, especially in a project that handles secrets.
- Accept correction and help repair harm when a conversation goes wrong.

Harassment, discrimination, threats, deliberate humiliation, sexualized conduct, and publishing another person's private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, security reports, and other spaces where someone is representing the Envryn project.

## Reporting

Report conduct concerns privately to the repository owner through GitHub. Security vulnerabilities belong in [private vulnerability reporting](https://github.com/Gr33nOps/Envryn/security/advisories/new), not in a conduct report or public issue.

Maintainers may edit or remove contributions that violate this standard and may temporarily or permanently restrict participation. Reports will be reviewed as promptly and privately as practical.

This code of conduct is adapted from the intent of the Contributor Covenant while using language specific to this project and community.
