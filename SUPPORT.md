# Getting help

Envryn is maintained as an open source beta project. The fastest way to get useful help is to choose the right channel and include enough detail to reproduce the problem.

## Bugs

Open a [bug report](https://github.com/Gr33nOps/Envryn/issues/new/choose) and include:

- Envryn version
- Windows or Android version
- What you expected
- What happened instead
- Reproduction steps
- Relevant logs with secrets and personal data removed

Do not attach a vault database, backup, master password, recovery code, API key, token, or private key.

## Ideas and questions

Use the feature request template for product ideas. Keep each request focused on one problem so it can be discussed and tracked clearly.

## Security issues

Do not open a public issue for a vulnerability. Follow the [security policy](.github/SECURITY.md) and use [private vulnerability reporting](https://github.com/Gr33nOps/Envryn/security/advisories/new).

## Installation warnings

The current Windows beta is not code-signed, so SmartScreen may show an unknown publisher warning. Android is distributed as an APK from GitHub and may require permission to install unknown apps. Always download from the official Releases page and verify `CHECKSUMS.txt`.
